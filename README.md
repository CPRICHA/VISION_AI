# 📘 AI-Based Eye Disease Detection System

---

## 🔍 Overview

This project is an AI-powered eye disease detection system designed for **early and accessible diagnosis**.
It analyzes both **external eye images** and **retinal fundus scans** using deep learning to identify eye conditions quickly and accurately.

---

## 🚀 Key Features

* 👁️ **Dual Image Analysis**
  Supports both external eye images and retinal scans

* 🧠 **Deep Learning Model**
  CNN with transfer learning for high accuracy

* ⚡ **Instant Results**
  Predicts disease type, severity, and confidence score

* 🔥 **Explainable AI**
  Grad-CAM heatmaps for visual interpretation

* 📶 **Offline Emergency Support**
  Provides nearby hospital contacts

* 💬 **AI Chatbot**
  Answers user queries and explains results

---

## ⚙️ Tech Stack

* Python, OpenCV
* TensorFlow
* NumPy, Pandas
* FastAPI / Flask (Backend)
* HTML, CSS, JavaScript (Frontend)

---

## 🧠 How It Works

1. **Image Input**
   User uploads an external eye image or retinal scan

2. **Preprocessing**
   Resize to 224×224, normalize pixel values, and apply CLAHE for contrast enhancement

3. **Model Inference**
   CNN extracts features and classifies the disease

4. **Output**
   Displays prediction, severity level, and confidence score

5. **Visualization**
   Grad-CAM highlights affected regions

---

## 💡 Highlights

* Combines **external + retinal analysis** for improved accuracy
* Uses **transfer learning** for efficient model training
* Integrates **chatbot and emergency support** for real-world usability

---

## 🏁 Conclusion

This system demonstrates how AI can make eye screening **faster, affordable, and accessible**, especially in low-resource environments.
